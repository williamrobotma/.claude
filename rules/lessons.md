# Lessons (from corrections)

- Migration/config/inventory work: every item gets an explicit user decision; there is
  no valid default in either direction. "Drop it, it's version-specific/old" and "keep or
  record it, it existed" are the same bug (a default substituted for an interview). For each
  item: state the FUNCTION it serves, then ask keep / translate / drop - and record who
  decided and when next to the item. An "interview me" prompt means this applies to every
  action in the task, including doc/recipe writing, not just file copies. (2026-07-09,
  WSL 2004->2604 migration: first skipped apt sources as "focal-pinned", then wrote a
  restore-recipes table presuming all functions wanted - corrected both times.)
